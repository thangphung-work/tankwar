# Tactical SPG Command 3D

**Chiến Địa Pháo Kích Tự Hành 3D**: a 10 vs 10 browser game of armored
artillery warfare, built with three.js.

## Play locally

```bash
npm install
npm start      # then open http://localhost:8080
```
